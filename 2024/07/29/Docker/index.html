Docker

1.引言

Docker 提供了在松散隔离的环境（称为容器）中打包和运行应用程序的功能。隔离性和安全性提供在给定主机上同时运行多个容器的功能。容器是轻量级的，包含运行应用程序所需的一切，因此无需依赖主机上安装的内容。可以在工作时共享容器，并确保与共享的每个人都能获得以相同方式工作的同一容器。
